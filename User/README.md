# User Notes – AutoNect AI Context

This folder stores persistent notes for the AI assistant across sessions.

| File | Purpose |
|------|---------|
| `Context.md` | Persistent chat log – the AI can append here to remember context across conversations. |
| `User.md` | Your profile: name, preferences, permissions, etc. |
| `Guidelines.md` | Instructions for the AI: shell safety, efficiency tips, and general guidelines. |
| `Journal.md` | Historical log of mistakes (lessons learned) and happy moments. |
| `Plans.md` | Your goals, roadmap, and project plans. |

Feel free to edit any file directly.

*The original `USER.md` is kept untouched for reference.*
